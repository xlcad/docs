# Text Alignment

Defines the allowed values for a text alignment.

## Category

Enumerations

## Allowed values

| Value | Description |
|---|---|
| 0 | Top-Left |
| 1 | Top-Center |
| 2 | Top-Right |
| 3 | Middle-Left |
| 4 | Middle-Center |
| 5 | Middle-Right |
| 6 | Bottom-Left |
| 7 | Bottom-Center |
| 8 | Bottom-Right |

## Minimum version

1.0.3019.0
