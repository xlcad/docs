# Brush Style

Defines the allowed values for a brush style.

## Category

Enumerations

## Allowed values

| Value | Description |
|---|---|
| -1 | Solid |
| 0 | Horizontal lines |
| 1 | Vertical lines |
| 2 | Downward diagonal lines |
| 3 | Upward diagonal lines |
| 4 | Cross |
| 5 | Diagonal cross |

## Minimum version

1.0.3019.0
