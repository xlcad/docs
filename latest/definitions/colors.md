# Colors

Defines how colors are represented and managed.

## Category

Definitions

## Content

Colors are represented using [Integer](../types/integer.md) values. Supported values range from `-1` to `16777215`, although allowed values may depend on the context.

- Color value `-1` represents transparency.
- Standard colors are defined in the [Standard Color](../enumerations/std_color.md) enumeration.
- Custom color values may be obtained using the XL CAD feature `Parameters > Colors > Custom`.

## Minimum version

1.0.3019.0
