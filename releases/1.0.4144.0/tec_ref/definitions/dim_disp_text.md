# Dimension displayed text

Defines how dimension text is represented and managed.

## Category

Definitions

## Content

- Every dimensioning instruction exposes the following parameters: required `Style` and optional `Text`.
- If the `Text` parameter is omitted, the measured size is displayed using the format specified in the dimension style instruction referenced by the `Style` parameter.
- If custom text is required for the `Text` parameter, use the `<>` symbol to display the measured size using the format specified in the dimension style instruction referenced by the `Style` parameter.

## Minimum version

1.0.3019.0
