# Image formats

Defines the supported image formats.

## Category

Definitions

## Content

The following image formats are supported when the corresponding encoder is available on the system.

|Format|File extensions|
|---|---|
|BMP|.bmp|
|EMF|.emf|
|EXIF|.exif|
|GIF|.gif|
|HEIF|.heif|
|ICON|.ico|
|JPEG|.jpg .jpeg|
|PNG|.png|
|TIFF|.tif .tiff|
|WEBP|.webp|
|WMF|.wmf|

## Minimum version

1.0.3309.0
