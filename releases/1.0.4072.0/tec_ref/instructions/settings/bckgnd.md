# ^^BCKGND

Defines the background properties of the drawing.

## Category

Drawing settings

## Parameters

| Ordinal | Name | Description | Type | Required | Allowed values |
|---|---|---|---|---|---|
| 1 | Color | Specifies the drawing background color. | [Integer](../../types/integer.md) | Yes | -1 to 16777215 |

## Example

| Instruction | Param 1 |
|---|---|
| ^^BCKGND | 0 |

## Notes

- This instruction is subject to the rules of the [Drawing Settings Instructions](../../definitions/drw_stg_instr.md).
- See [Colors](../../definitions/colors.md) for additional information about the `Color` parameter.

## Minimum version

1.0.3019.0
