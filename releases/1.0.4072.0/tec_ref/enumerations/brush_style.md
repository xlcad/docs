# Brush style

Defines the allowed values for a Brush style.

## Category

Enumerations

## Allowed values

| Value | Description |
|---|---|
| -1 | Solid |
| 100 | Horizontal lines |
| 101 | Vertical lines |
| 102 | Downward diagonal lines |
| 103 | Upward diagonal lines |
| 104 | Cross |
| 105 | Diagonal cross |
| 106 | Concrete |
| 107 | Brick |
| 108 | Stone |
| 109 | Ground |
| 110 | Gravel |
| 111 | Sand |
| 112 | Steel |
| 113 | Insulation |

## Notes

The following codes are maintained for compatibility with older versions.

| Value | Description |
|---|---|
| 0 | Horizontal lines |
| 1 | Vertical lines |
| 2 | Downward diagonal lines |
| 3 | Upward diagonal lines |
| 4 | Cross |
| 5 | Diagonal cross |

## Minimum version

1.0.4072.0
