# Instructions Hierarchy

Defines how instructions defined in parent and referenced worksheets are managed.

## Category

Definitions

## Content

The following instruction categories are managed according to these rules:

1. **Drawing settings**  
Instructions defined in a parent worksheet take precedence over the same instructions defined in referenced worksheets.

2. **Drawing resources**  
Instructions defined in a parent worksheet take precedence over the same instructions defined in referenced worksheets, but only if they share the same identifier (`Name` parameter).
