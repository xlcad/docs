# ^^ANTIALIAS

Defines whether antialiasing is applied to the drawing.

## Category

Drawing settings

## Parameters

| Ordinal | Name | Description | Type | Required | Allowed values |
|---|---|---|---|---|---|
| 1 | Apply | Specifies whether antialiasing is applied to the drawing. | [Boolean](../../types/boolean.md) | Yes | See [Boolean](../../types/boolean.md) allowed values. |

## Example

| Instruction | Param 1 |
|---|---|
| ^^ANTIALIAS | 1 |

## Notes

- This instruction is subject to the rules of the [Drawing Settings Instructions](../../definitions/drw_stg_instr.md).

## Minimum version

1.0.3019.0
