# Overview

XL CAD is a parametric drawing engine embedded in Microsoft Excel that allows you to generate technical drawings directly from spreadsheet models.

Unlike traditional CAD applications, XL CAD does not require drawings to be created interactively. Instead, drawings are generated by executing drawing instructions stored in worksheet cells. Since instruction parameters can reference other cells, the resulting drawings automatically adapt to changes in the underlying spreadsheet data.

This approach enables spreadsheet models to become the single source of truth for both engineering calculations and technical drawings, eliminating the need to manually synchronize data between spreadsheets and external CAD software.

XL CAD provides a comprehensive set of drawing instructions that can be combined to generate parametric 2D drawings, including geometric entities, dimensions, text, reusable resources, arrays, and drawing settings.

Because drawing instructions are fully integrated into Excel, they can take advantage of formulas, functions, tables, named ranges, and automation features already available in the spreadsheet environment. This allows complex engineering models to generate drawings dynamically while remaining easy to customize and maintain.

The primary benefits of XL CAD include:

- Eliminating repetitive drawing operations.
- Keeping drawings synchronized with engineering calculations.
- Reusing drawing logic across multiple projects.
- Reducing manual errors caused by duplicated data.
- Leveraging Microsoft Excel as both a calculation and drawing environment.

This documentation describes the XL CAD drawing language, its instruction set, supported data types, reusable resources, drawing settings, and the concepts required to build parametric drawing models.
